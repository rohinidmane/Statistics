# 📊 Statistics – Descriptive Statistics

This project covers the fundamentals of descriptive statistics, including measures of central tendency, variability, and shape. It uses Python libraries to calculate statistical measures and understand data distribution through practical examples.

## 📊 What This Project Does

- Calculates Mean, Median, and Mode.
- Understands measures of variability.
- Calculates Range, Variance, and Standard Deviation.
- Explores statistical analysis using a Titanic dataset.
- Understands Skewness and Kurtosis.
- Uses Python libraries for statistical calculations.

## 📈 Statistical Operations Performed

| Operation           | Purpose                                   |
|---------------------|-------------------------------------------|
| `np.mean()`         | Calculates the average                    |
| `np.median()`       | Finds the middle value                    |
| `stats.mode()`      | Finds the most frequently occurring value |
| `np.ptp()`          | Calculates the range                      |
| `np.var()`          | Calculates population variance            |
| `np.std()`          | Calculates population standard deviation  |
| `skew()`            | Measures distribution asymmetry           |
| `kurtosis()`        | Measures distribution shape               |
| `df.info()`         | Displays dataset information              |
| `max()` and `min()` | Find maximum and minimum values           |
